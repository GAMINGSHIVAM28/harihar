```bash

# - services_new.html → services.html (rename)

# - contact_new.html → contact.html (rename)
# - css_style.css → css/style.css (move + rename)
# - js_script.js → js/script.js (move + rename)
```

### Step 2: Test Locally
1. Install **Live Server** extension in VS Code
2. Right-click `index.html` → **Open with Live Server**
3. Website opens at `http://localhost:5500`

### Step 3: Deploy to GitHub Pages
1. Commit all files to your GitHub repo
2. Settings → Pages → Deploy from branch (main, /root)
3. Done! Website is live

## 🎨 Customization Quick Reference

### Update Contact Info
**All files** - Find and replace:
- `+91 99812 20777` → Your phone
- `919981220777` → Your WhatsApp
- `Bilaspur, Chhattisgarh` → Your location

### Update Business Name
**All files** - Find and replace:
- `Harihar Wholesale Pharmacy` → Your business name
- `Wholesale Medicine Supplier in Bilaspur` → Your tagline

### Update Medicine Stock
**js/script.js** - Edit `medicineDatabase` array (lines 12-80):
```javascript
const medicineDatabase = [
  {
    id: 1,
    name: 'Your Medicine Name',
    company: 'Your Company',
    category: 'Your Category',
    stock: 'Available', // or 'Limited' or 'Out of Stock'
    note: 'Your note about the medicine'
  },
  // ... add more
];
```

### Add Categories
**stock_new.html** - Add filter buttons (line ~64):
```html
<button class="filter-btn" data-category="New Category">New Category</button>
```

### Change Colors
**css/style.css** - Edit CSS variables (lines 20-28):
```css
--primary-green: #1a7a5c;      /* Main color */
--light-green: #2d9a77;        /* Lighter */
--soft-mint: #e8f5f2;          /* Light background */
--dark-navy: #1a2332;          /* Text */
```

## 🌐 GitHub Pages Setup (3 Steps)

1. **Commit to GitHub**
   ```bash
   git add .
   git commit -m "Convert React to static HTML CSS JS"
   git push origin main
   ```

2. **Enable Pages**
   - Go to Repository → Settings → Pages
   - Source: Deploy from branch
   - Branch: main
   - Folder: / (root)

3. **Done!**
   - Website live at: `https://yourusername.github.io/repo-name`
   - Updates automatically on every push
